ANIPLATO — plain JavaScript webpage

HOW TO OPEN
1. Extract this ZIP completely.
2. Double-click index.html (or use VS Code Live Server).
3. Keep index.html, styles.css, script.js, and assets/ together.

FILES
index.html  — page content and layout
styles.css  — colors, typography, responsive layout
script.js   — menu, route tabs, role tabs, workflow, rating, and demo feedback
assets/     — original logo and illustration
ATTRIBUTION.txt — original asset and icon licenses

No Node.js, npm, React, TypeScript, Java, or MySQL installation is required to view this webpage.

FEEDBACK
This standalone copy stores demo feedback in this browser only, using localStorage under aniplato_demo_feedback. It does not send responses to the project team. To clear demo records, clear this site's browser data. Some browsers restrict storage on file:// pages; use VS Code Live Server if saving is unavailable.
A real shared feedback database needs a backend. An optional endpoint can be configured at the top of script.js; it must accept the documented JSON form fields and allow this website's origin. No server or database credentials are included.

WINDOWS DOWNLOAD
The Windows installer has not been supplied or uploaded, so no live installer-download button is included. Once it exists, add its real GitHub Release download URL to index.html.

HOSTING
These files can be uploaded to static hosting. The publicly hosted website is not changed by editing this ZIP.
