ANIPLATO - getting started
=========================

ANIPLATO is a surplus-food board for Metro Manila. Donors post surplus food, food groups
post what they need, and an admin verifies who is who.

This copy uses YOUR OWN database. Nothing is shared with anyone else, and no one else can
see your data.


WHAT YOU NEED
-------------
1. Windows 10 or 11. Java is already inside this folder.
2. A MySQL database, version 8.0.16 or newer, that this computer can reach. It can be:
   - MySQL installed on this computer (free: MySQL Community Server), or
   - a MySQL database from any hosting provider.
   You need its host, port, a user name and a password. A provider may also give you a
   certificate file (usually ca.pem).
3. Optional: a free key for the help assistant, and a Gmail "app password" for sending email.
   The app works without both.


FIRST RUN
---------
1. Keep everything in this folder together. Double-click ANIPLATO.exe.
2. If Windows says "Windows protected your PC", choose More info, then Run anyway.
   (The program is not code-signed, so Windows asks the first time.)
3. The Setup screen opens. Fill in the host, port, database name (aniplato is fine),
   user and password. Add the certificate file only if your provider gave you one.
4. Click Test connection. The screen tells you what it found:
   - Empty: the database is ready. Type the email and password you want for your admin
     account, then click Create.
   - Already set up: ANIPLATO is there already (for example you set it up on another
     computer). Click Connect to use it as it is. Nothing in it is changed.
   - Cannot continue: the screen says why (wrong password, cannot reach the server, MySQL
     too old, not allowed to create tables). Fix that and test again.
5. Sign in with the admin email and password you just chose.
6. Register a donor and a food group from the sign-in screen's Register link, then approve
   them from the admin screens. The board is empty until people post.

Setup never deletes or replaces anything in a database that already has data.


WHERE YOUR SETTINGS ARE KEPT
----------------------------
%APPDATA%\ANIPLATO\db.properties   (paste that into the Explorer address bar)

It holds your database password in plain text, so keep it private. To point the app at a
different database, choose "Change database settings" on the sign-in screen after a
database problem, or delete that file and start the program again.

Optional lines you can add to that file:
  ai.gemini.api-key=<your key>     the help assistant (make a free key at
                                   https://aistudio.google.com/app/apikey)
  mail.user= and mail.password=    email (a Gmail address and its app password from
                                   https://myaccount.google.com/apppasswords)
Close and reopen the program after editing the file.


DOING IT BY HAND (instead of the Setup screen)
----------------------------------------------
1. In your MySQL, create a database and run sql\schema.sql in it. This creates the tables only.
2. Run sql\seed.sql in the same database. It creates one admin account,
   admin@aniplato.test, with the password Aniplato123!. The app makes you choose a new
   password the first time you sign in.
3. Copy db.properties.example to db.properties (in this folder, or in %APPDATA%\ANIPLATO),
   and fill in url, user and password.


PROBLEMS
--------
"Cannot reach <host>:<port>"      Check the address, the port, your internet, and that MySQL
                                  is running.
"did not accept that user name"   The user name or password is wrong.
"not allowed to create"           Use a user with permission, or create an empty database
                                  yourself and give the user rights on it.
"already has some of the tables"  The database holds part of an old ANIPLATO. Use an empty
                                  database or a different name. Nothing was changed.
The assistant says it is not set up   Add your own key, as above.
